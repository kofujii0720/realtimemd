# SCR-0301 エクスポート設定モーダル

## 1. 目的
ドキュメントのPDF/HTMLエクスポート条件（出力形式、用紙サイズ等）を設定し、ダウンロード処理を実行する。

## 2. 画面構成
- ヘッダー: タイトル「ドキュメントのエクスポート」
- 入力領域: 出力フォーマットラジオボタン、用紙サイズセレクト、マージン設定
- フッター: キャンセルボタン、ダウンロードボタン

## 3. 表示項目
| 項目名 | data-testid | 型 | 取得元 | 表示条件 | 書式 |
|---|---|---|---|---|---|
| 出力フォーマット | export-format-radio | String | 選択状態 | 常時 | PDF / HTML |
| 用紙サイズ | export-paper-select | String | 選択状態 | PDF選択時 | A4 / Letter |

## 4. 入力項目
| 項目名 | data-testid | 型 | 必須 | 制約 | 初期値 |
|---|---|---|---|---|---|
| フォーマット | export-format-radio | String | YES | PDF / HTML | PDF |
| 用紙サイズ | export-paper-select | String | YES | A4 / Letter | A4 |

## 5. 操作と遷移
| 操作 | data-testid | 前提条件 | 呼び出すAPI | 成功時 | 失敗時 |
|---|---|---|---|---|---|
| ダウンロードボタン | btn-submit-export | フォーム妥当 | `API-0301` | モーダルを閉じダウンロード実行 | エラーメッセージ表示 |
| キャンセルボタン | btn-cancel-export | なし | なし | モーダルを閉じる | なし |

## 6. 状態と表示の対応
| 状態 | 表示 |
|---|---|
| 読込中 | ダウンロード処理中、ダウンロードボタンを活性スピナー表示にする (`export-processing-spinner`)。 |
| 0件 | 設定可能なオプション項目が指定なし状態の場合、デフォルト設定を自動適用表示する。 |
| 正常 | フォーマット選択および設定項目が正常表示されたモーダルダイアログ。 |
| エラー | 生成処理失敗時、モーダル内に警告アラートメッセージを表示する。 |

## 7. 非機能・アクセシビリティ
- Escキー押下でモーダルを閉じる。

## 8. 要確認事項
なし
