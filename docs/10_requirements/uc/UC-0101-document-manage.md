# UC-0101 ドキュメント管理（作成・更新・一覧表示・削除）

## 1. 概要
ユーザーがMarkdownドキュメントの新規作成、保存更新、ドキュメント一覧の閲覧、不要ドキュメントの削除を行う。

## 2. 事前条件
アプリが正常に起動し、FastAPIバックエンドと接続されていること。

## 3. 基本フロー
1. ユーザーが画面上でドキュメント一覧を確認する (`API-0101`)。
2. ユーザーが一覧からドキュメントを選択すると、詳細データ（本文・タイトル）が取得・表示される (`API-0105`)。
3. 「新規作成」ボタンをクリックすると空のドキュメントが作成される (`API-0102`)。
4. エディタで編集を行い、保存操作を行うことで変更が保存される (`API-0103`)。
5. 不要なドキュメントの「削除」ボタンをクリックすると確認ダイアログ表示後、削除される (`API-0104`)。

## 4. 代替フロー
| # | 分岐 | 挙動 |
|---|---|---|
| 4a | 本文サイズが2MBを超過 | エラーメッセージを表示し保存を中断する (`E-0103-002`) |
| 4b | 対象ドキュメントが存在しない | エラーダイアログを表示し一覧を再取得する (`E-0103-001`) |

## 5. 事後条件
DB (`TBL-0001`) 上にドキュメントの状態が正しく永続化されること。

## 6. 業務ルール
| ID | ルール |
|---|---|
| BR-0101-1 | 無操作1.5秒で自動下書き保存を実行する (`REQ-0003`) |
| BR-0101-2 | 明示保存時のみ変更履歴 (`TBL-0002`) を作成する |

## 7. 関連
- 画面：SCR-0101
- API：API-0101, API-0102, API-0103, API-0104, API-0105
