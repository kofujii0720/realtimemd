# UC-0301 PDF/HTML エクスポート

## 1. 概要
現在編集中のドキュメントを、スタイル崩れのないPDF形式または単体HTMLファイルとしてダウンロード出力する。

## 2. 事前条件
ドキュメントが選択または作成されていること。

## 3. 基本フロー
1. ユーザーが「エクスポート」ボタンをクリックし、エクスポートモーダル (`SCR-0301`) を開く。
2. 出力フォーマット（PDF または HTML）およびオプション（用紙サイズ・マージン）を選択する。
3. 「ダウンロード」ボタンをクリックすると、FastAPIバックエンドヘエクスポートリクエスト (`API-0301`) が送信される。
4. バックエンドで生成された binary blob データを受信し、ブラウザでファイル保存ダイアログを自動実行する。

## 4. 代替フロー
| # | 分岐 | 挙動 |
|---|---|---|
| 4a | PDF生成失敗 (サーバーエラー) | モーダル内にエラーメッセージ (`E-0301-001`) を表示する |

## 5. 事後条件
指定された形式で完全なファイルがダウンロード完了すること。

## 6. 業務ルール
| ID | ルール |
|---|---|
| BR-0301-1 | PDF出力時は画面CSSと共通のスタイル定義をサーバー側レンダラーへ適用する |

- API：API-0301
