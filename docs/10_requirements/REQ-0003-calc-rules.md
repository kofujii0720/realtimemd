# REQ-0003 事故防止厳格規則定義

本プロジェクトにおける文字コード、改行、日時、自動保存等のAI生成事故防止規則。

## 1. 文字コード・改行コード・ファイルエンコーディング
- **文字コード**: UTF-8 (BOMなし) 固定。
- **改行コード**: `LF` (`\n`) に統一。クライアントおよびサーバーでの入力時に `\r\n` は自動的に `\n` へ正規化する。
- **ファイルサイズ上限**: ドキュメント本文 (`content`) の最大容量は **2MB** (2,097,152 bytes)。超過時はバリデーションエラーとする。

## 2. 自動保存 (Auto-save) および明示保存
- **自動保存 (Auto-save)**: エディタ本文変更後、キー入力無操作状態が **1.5秒** (1500ms) 継続した場合、バックエンドに下書き更新APIを送信する。
- **明示保存 (Ctrl+S / Cmd+S / 保存ボタン)**: 即時に保存処理を呼び出し、履歴レコード (`TBL-0002`) を作成する。

## 3. 日時・タイムゾーン処理
- **保存形式**: ISO 8601 形式の UTC 文字列 (`YYYY-MM-DDTHH:mm:ss.sssZ`) とし、DB上は TEXT 型で格納する。
- **画面表示**: ブラウザのロケール設定に基づきローカルタイムゾーンで表示する。
- **ドメイン/ユースケース層の制約**: `usecases` および `domain` 層内で直接 `new Date()` や `datetime.now()` を実行することを禁止し、引数 `now` として受け取る。
