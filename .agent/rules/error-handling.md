# エラー処理規約 (error-handling.md)

## 1. エラーコード定義と形式
- エラーコードは `E-<API番号>-<3桁連番>` の形式とする（例: `E-0101-001`）。
- エラーレスポンス形式は統一する:
  ```json
  {
    "code": "E-0101-001",
    "messageKey": "error.document.notFound",
    "details": []
  }
  ```
- サーバー側は表示用日本語文言を直接返さず、`messageKey` を返し、フロントエンド側で `MSG-0001` (メッセージ辞書) を参照して描画する。

## 2. 例外のハンドリング
- 例外を何も処理せずに無視 (pass) することを禁止する。
- 定義外の例外は汎用 500 (E-0401-999) に変換し、元の例外・スタックトレースはサーバーログに記録する。
