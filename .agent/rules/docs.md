設計書（`docs/`）を編集する際は、必ずテンプレート (`.agent/doc-format/`) の必須セクションを全件網羅すること。
- 未確定事項を推測で埋めず、`## 8. 要確認事項` に列挙すること。
- 文書間の参照はすべて ID 参照（`SCR-0101.item.title` 等）とし、文章参照を禁止する。
- フック `scripts/hooks/block-docs-edit.sh` が作動するため、実装セッション中の直接編集は禁止。環境変数 `ALLOW_DOCS_EDIT=1` を付与して変更すること。
