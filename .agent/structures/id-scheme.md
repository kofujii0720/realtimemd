# ID採番規則 (id-scheme.md)

本プロジェクトにおける全識別子（ID）の付与規約。

## 1. 接頭辞と業務領域割当

### 接頭辞
- `REQ-`: 要件定義書 (4桁連番)
- `UC-`: ユースケース (上位2桁=領域, 下位2桁=連番)
- `SCR-`: 画面設計書 (上位2桁=領域, 下位2桁=連番)
- `TBL-`: テーブル設計書 (4桁連番)
- `API-`: API設計書 (上位2桁=領域, 下位2桁=連番)
- `VP-`: テスト観点表
- `MSG-`: メッセージ辞書
- `PLAN-`: 計画文書
- `E-`: エラーコード (`E-<API番号>-<3桁連番>`)
- `BR-`: 業務ルール (`BR-<UC番号>-<連番>`)
- `INV-`: 不変条件 (`INV-<連番>`)

### 上位2桁（業務領域・リソース割当）
- `01`: ドキュメント・ファイル管理
- `02`: エディタ・リアルタイムプレビュー
- `03`: エクスポート (PDF/HTML)
- `04`: システム設定・共通

## 2. 項目参照の書式
文章での曖昧な参照を禁止し、以下の記法で厳密に ID 参照すること。

- 画面項目: `SCR-0101.item.title`
- テーブル列: `TBL-0001.col.created_at`
- API入力: `API-0101.in.content`
- API出力: `API-0101.out.document_id`
- APIエラー: `API-0101.err.E-0101-001`
- メッセージキー: `MSG-0001.key.error.document.notFound`
